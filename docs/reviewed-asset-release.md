## 正式已有制品的独立发行审查

`reviewed-asset-release.yml` 仅审查固定已成功的正式整合制品，不重复编译原引擎。
核对双方源版本的正式门、原引擎真实处理门、完整逐文件 manifest、两个实际原生引擎、
独立 Spine 完整协议与 SDK 五 DLL／官方完整许可、真实安装／安全卸载收据。
输出六个原字节文件和独立 review.json，未知、候选、部分工具包或摘要不符即拒绝。
审查任务不自动发布，不包含本库私有源码；通过后才允许按既有授权发布完整产品。


草稿存储只保留 CI 文件，始终 draft=true，不能自动公开；以实际 GitHub 资产摘要核对并保存完整文件 manifest。不删除既有 Actions 产物或发行文件。
